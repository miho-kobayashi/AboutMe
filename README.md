# 1321プロジェクト概要

## LLMを用いた経済情報解釈と1321（日経225連動ETF）の予測可能性の検証

------------------------------------------------------------------------

# 概要

本プロジェクトでは、LLMを利用し、
経済ニュース・論文・市場レポートなどの非構造データを解釈し、
1321（日経225連動ETF）の将来価格予測へ活用できるかを検証しています。

単なる価格時系列ではなく、

-   経済イベント
-   市場心理
-   ニュース
-   論文
-   マクロ要因

を特徴量として扱い、

> 「文章情報は価格変動の予兆となり得るか」
> 「LLMは市場期待を特徴量化できるか」

を主な研究テーマとしています。

------------------------------------------------------------------------

# 背景

市場価格はテクニカル指標のみで形成されるわけではなく、

-   金融政策
-   地政学リスク
-   景気指標
-   市場心理
-   将来期待

などの影響を受けると考えています。

近年のLLMは高い文章理解能力を持つため、

> テキスト → 意味 → 特徴量 → 予測

への変換可能性を検証しています。

------------------------------------------------------------------------

# 理論的背景

市場価格は完全ランダムではなく、
参加者の期待・不安・将来予測の総和として形成されると考えています。

本研究では、

文章 →　意味　→　特徴量　→　予測 

という流れを仮定します。

LLMは単なるニュース要約ではなく、 **市場期待変化を推定する中間層**
として利用できる可能性があります。

------------------------------------------------------------------------

# 拡張仮説：文章力学（Language Dynamics）

本プロジェクトでは文章を静的情報ではなく、

**時間とともに変化する信号**

として扱える可能性に興味を持っています。

経済ニュースや論文のEmbeddingは 時系列的に変化すると考えられます。

例：

Embedding(t)

↓

速度: ΔEmbedding

↓

加速度: Δ²Embedding

↓

ジャーク: Δ³Embedding

この変化は、

-   市場期待変化
-   不安増幅
-   センチメント急変
-   トレンド転換

を表現している可能性があります。

------------------------------------------------------------------------

## 仮説

市場価格だけでなく、

**文章意味の速度・加速度・ジャーク**

も将来価格予測へ寄与する可能性があります。

------------------------------------------------------------------------

# FLAIRとの関連性（仮説）

FLAIRのような時系列予測手法では、

Level（基準） ↓ Shape（周期） ↓ 変動

の分解を行います。

本研究では類似発想として、

Embedding系列 ↓ 周期性 ↓ 意味変化 ↓ 市場期待変化

を捉えられないか検討しています。

厳密にはFLAIRと異なるものの、

> 「意味の変化を波形として扱う」

という思想に関心があります。

------------------------------------------------------------------------

# 検証仮説

1.  経済ニュースや論文は将来価格変動に対して予測可能な情報を含む\
2.  LLMは高次特徴量を生成できる\
3.  価格 + テキスト + マクロ情報 の組み合わせは性能向上につながる\
4.  Embeddingの速度・加速度・ジャークは市場期待変化を表現できる可能性がある
